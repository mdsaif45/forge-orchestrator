# Forge Roadmap & Planning

This directory contains the authoritative roadmap, milestone definitions, dependency graphs, and deferred work records for Forge.

---

## The Rule of Planning Truth

> **Roadmap is planning truth, not implementation truth.**

A roadmap item records *intent*, *grouping*, and *dependencies*. The existence of an issue, task ID, or milestone table does not prove that code exists or that tests pass. For the verified state of actual implementation, consult [`docs/project/current-state.md`](../project/current-state.md).
