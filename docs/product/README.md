# Forge Product Documentation

This directory contains the authoritative statements of product intent, vision, core principles, and the user workflow that Forge is designed to serve.

## Authority & Principles

Product documentation defines the *destination* and the *invariants*. Technical architecture and implementation must conform to the principles articulated here. If an architectural design or code implementation conflicts with these documents, the design or implementation is flawed, not the product mandate.
